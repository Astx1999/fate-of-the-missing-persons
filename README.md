# The Fate of the Missing Persons

Conference landing page for **Humanitarian Dialogue and Cooperation**  
19–20 November 2026, Yerevan, Armenia.

Implemented from the Figma design (`Frame 1`).

## Stack

- React 19 + TypeScript
- Vite
- SCSS (Sass)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Structure

```
src/
  assets/        # logos, speakers, map, hero art from Figma
  components/    # Header, Hero, About, Themes, Programme, Speakers, Partners, Venue, Footer
  data/          # programme + speakers content
  styles/        # design tokens and mixins
```
